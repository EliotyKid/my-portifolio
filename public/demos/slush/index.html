03 / SEM PONTAS SOLTAS

Resposta simples.

Começar algo novo traz perguntas.
Vamos tirar algumas do caminho.

O que é a Slush?+

Uma carteira digital para explorar o ecossistema Sui: ativos, colecionáveis e novas experiências em um só lugar. Esta página é uma demonstração visual independente.

Preciso entender de cripto para começar?+

Não. A ideia é deixar o complicado nos bastidores. Você pode conhecer a interface pela demonstração, sem criar conta ou conectar uma carteira.

Esta demonstração usa dinheiro real?+

Não. Todos os saldos, tokens e colecionáveis exibidos são fictícios. Nenhuma transação é realizada e nenhum dado financeiro é solicitado.

Como este site foi criado?+

Com Next.js, GSAP no letreiro e Framer Motion nas interações. O visual segue o DESIGN.md: cores chapadas, tipografia gigante e adesivos com contorno preto.
